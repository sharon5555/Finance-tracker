# 💰 Finance Tracker

A modern and responsive **Personal Finance Tracker** built with **React, Tailwind CSS, Firebase, and Chart.js**. This application helps users manage their personal finances by tracking income, expenses, savings, and spending habits through an intuitive dashboard and interactive charts.

---

## 📖 About the Project

Managing personal finances is an important part of everyday life. This project was created to provide a simple, secure, and user-friendly way for users to record their financial transactions and visualize their spending patterns.

Users can create an account, securely log in, add income and expense records, categorize transactions, and monitor their financial health through beautiful charts and summaries.

---

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/finance-tracker.git
```

### Navigate into the Project

```bash
cd finance-tracker
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```
